# Workspaces

Qtile creates nine plain groups with padded names: ` I ` through ` IX `. They
share identical layouts, floating rules and key behaviour. Their only per-group
specialisation is a wallpaper and generated colour palette.

| Group | Wallpaper expected | Behaviour |
|---|---|---|
| I | `I.png` | Standard; blue/sand palette |
| II | `II.png` | Standard; green/orange palette |
| III | `III.png` | Standard; blue/brown palette |
| IV | `IV.png` | Standard; violet/pink palette |
| V | `V.jpg` | Standard; blue/red palette |
| VI | `VI.png` | Standard; navy/red palette |
| VII | `VII.png` | Standard; green palette |
| VIII | `VIII.jpg` | Standard; blue/rust palette |
| IX | `IX.png` | Standard; brown/green palette |

No application assignment, exclusive layout or workspace-specific floating
rule is present.
